CHAPTER 01·~20 min·setup

Setup

Three things on your laptop, one secret in a file, one smoke-test command. By the end of this chapter your terminal will be talking to Claude.

Goal

Install bun, get an Anthropic API key, copy the example-agent project, run a one-line smoke test, and confirm the response came back. If that works, every other chapter will work.

1. Install bun (or skip if you already have Node 22)

bun is a fast JavaScript runtime that runs TypeScript files directly — no build step, no transpiler config. We use it because it makes the examples in this tutorial three lines shorter. If you'd rather use Node 22+, every command works with npx tsx instead.

On macOS or Linux:

curl -fsSL https://bun.sh/install | bash

On Windows, use WSL and run the same command inside it.

Then verify:

bun --version
# 1.x.x or newer
If bun is fighting you

Use Node 22+ instead — it works identically. Wherever the tutorial says bun run X.ts, run npx tsx X.ts instead. Get Node from nodejs.org or brew install node.

2. Get an Anthropic API key

Go to console.anthropic.com/settings/keys. Sign in (or sign up — there's a free credit tier that covers this tutorial). Click Create Key. Copy the key that starts with sk-ant-....

The key is shown exactly once

Anthropic only shows your API key at the moment of creation. If you close the page without copying it, you have to make a new one. Paste it somewhere safe right away.

3. Clone the project

The TypeScript code you'll build alongside this tutorial lives at github.com/LeadPages/leadpage-creator-agent. From a terminal: 

git clone https://github.com/LeadPages/leadpage-creator-agent.git
cd leadpage-creator-agent/example-agent

# Install dependencies (one Anthropic SDK, one types package).
bun install

# Copy the env template and put your key in it.
cp .env.example .env
# Open .env in your editor and replace sk-ant-REPLACE_ME with your real key.

Your .env should now look like:

ANTHROPIC_API_KEY=sk-ant-api03-abc...your_real_key...xyz
DEFAULT_MODEL=claude-sonnet-4-6

4. The smoke test

Let's confirm the SDK, the key, and the network all work. Create a file called smoke.ts inside the example-agent/ directory you just cloned, with this content: 

import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const response = await client.messages.create({
  model: "claude-haiku-4-5-20251001",  // cheapest model — fine for a smoke test
  max_tokens: 64,
  messages: [{ role: "user", content: "Reply with exactly: pong." }],
});

console.log(response.content);

Run it:

bun run smoke.ts

You should see something like:

[ { type: "text", text: "pong." } ]
If you saw "pong" — you're done.

The SDK loaded, your key worked, and Claude responded. Delete smoke.ts and move on. (You won't need it again — the rest of the chapters have their own commands.)

If it didn't work

ErrorLikely causeFix
Could not resolve "@anthropic-ai/sdk" You skipped bun install or ran it in the wrong directory. cd example-agent && bun install
401 authentication_error Your .env still has the placeholder, or you pasted the key with quotes. Open .env, no quotes around the key, no trailing space.
ANTHROPIC_API_KEY not set Either you didn't cp .env.example .env, or bun isn't picking up the file. Make sure the .env file is in example-agent/, not in the parent directory.
429 rate_limit_error You used a key from a workspace with no credits. Add billing at console.anthropic.com, or wait — the free tier resets daily.

What you have now

A cloned leadpage-creator-agent/example-agent/ directory, a real API key wired in, and a runtime that can call Claude. That's everything the rest of the tutorial needs.

Checkpoint
You ran bun run smoke.ts and got 401 authentication_error. The error went away after you fixed your .env. What was almost certainly wrong with it?
bun reads .env automatically; you never have to import a library to load it. A 401 means the key the SDK sent over the wire was syntactically valid but wasn't an actual issued key — which almost always means the placeholder is still there or something extra (like wrapping quotes) is on the line.
