What you'll build

A Leadpage Creator — an agent that takes a one-line brief like "vegan meal kits for busy parents" and produces a complete, polished landing page. By the end it will:

  • Pick its own colors via a tool that fetches a brand's palette from a URL.
  • Load instructions on demand — a copywriting skill and a hero-layout skill that get pulled into context only when needed.
  • Delegate to a copywriter subagent and a designer subagent, each tuned for its job.
  • Remember your brand across sessions so you don't repeat yourself.
  • Be measured, not vibed — every change runs against an eval set so you can see what improved.
  • Stream, retry, and call out to MCP servers (like HTMLPub) so it can publish, not just print.
  • Ship as a Claude Managed Agent that anyone on your team can call.

How the tutorial works

Each chapter is one focused lesson with a clear goal, a walkthrough, a code snippet you can run, an "expected output" block, and a one-question checkpoint quiz. Getting the quiz right marks the chapter complete in the sidebar — your progress is saved in localStorage so you can come back later.

Alongside this site is a TypeScript project at ../example-agent. Each chapter has a matching source file there (e.g. Chapter 03 → src/03-tools.ts), and the chapter tells you exactly when to run it. You're meant to keep a terminal open and switch between them.

How to use the chapter cards

Click any chapter to jump in. They build on each other, so reading them in order is best — but you can revisit any chapter at any time.

What this isn't

This is not an API reference, and it's not a survey of every Claude feature. It's a guided path that picks one defensible way to build a real agent and walks you down it. When a chapter mentions a feature you could swap in (the Agent SDK, MCP, Vault, sub-agents), we'll point at the original CWC workshop where that path is taught, but the tutorial itself stays on the rails.
