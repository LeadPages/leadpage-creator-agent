CHAPTER 02·~15 min·API basics

First call

One prompt in, one HTML page out. No tools, no loop. The smallest thing that could possibly be called a "Leadpage Creator," to give you something concrete to make better.

Goal

Make exactly one messages.create call. Save the result to disk. Open it in a browser. By the end you'll understand the four parameters every Claude call needs, and you'll see the thing that's broken about a no-loop agent (it'll be obvious).

The whole program

The source for this chapter is already in your project at example-agent/src/02-first-call.ts. Open it now — here's what's in it: 

import { mkdir, writeFile } from "node:fs/promises";
import { client, DEFAULT_MODEL, extractHtml, firstText } from "./shared/client.ts";
import { PROMPT_NAIVE } from "./shared/prompts.ts";

async function main() {
  const topic = process.argv.slice(2).join(" ").trim() || "vegan meal kits for busy parents";

  const response = await client.messages.create({
    model: DEFAULT_MODEL,                                  // claude-sonnet-4-6
    max_tokens: 4096,
    system: PROMPT_NAIVE,                                  // instructions
    messages: [
      { role: "user", content: `Create a landing page for: ${topic}` },
    ],
  });

  const html = extractHtml(firstText(response.content));

  await mkdir("out", { recursive: true });
  await writeFile("out/02-first-call.html", html, "utf8");
  console.log("✓ wrote out/02-first-call.html");
  console.log(`  ${response.usage.input_tokens} in · ${response.usage.output_tokens} out`);
}

main().catch(console.error);

That's the whole thing. Forty lines, most of it ceremony.

The four parameters

Every messages.create call has these four:

ParamWhat it isHere, what we used
modelWhich Claude. Pricing and quality scale with this.claude-sonnet-4-6 — balanced default.
max_tokensHow long the reply can be. Hard limit; the model will stop.4096 — comfortably enough for a landing page.
systemThe role / rules / persistent instructions. Counted as input tokens.A 12-line prompt that says "you make landing pages, here's the format."
messagesThe conversation. For a one-shot call, just [{role: "user", content: "..."}].One user message with the topic embedded.
